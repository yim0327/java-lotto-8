# java-lotto-precourse

# 기능 목록 정리


## 입력
- [x] 사용자는 **로또 구입 금액**을 입력할 수 있다.

  - [x] 금액은 1,000원 단위로만 입력 가능하다.

- [x] 사용자는 **당첨 번호**를 입력할 수 있다.

  - [x] 당첨 번호는 숫자 6개를 입력받는다.

  - [x] 당첨 번호는 쉼표(,)를 기준으로 구분한다.

    - `ex) 1,2,3,4,5,6`

  - [x] 당첨 번호는 로또 번호 규칙을 따른다.

- [x] 사용자는 **보너스 번호**를 입력할 수 있다.

  - [ ] 보너스 번호는 숫자 1개를 입력받는다.

  - [x] 보너스 번호는 로또 번호 규칙을 따른다.

  - [x] 보너스 번호는 당첨 번호와 중복되지 않는다.


## 출력
- [x] 구입 금액 입력 안내 메시지를 출력한다.

- [ ] 발행한 로또 수량 및 번호를 형식에 맞게 출력한다.
  ```
  ex) 로또 수량 및 번호 출력 형식
    
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
  ```

  - [ ] 로또 번호는 오름차순으로 정렬하여 보여준다.

- [ ] 당첨 내역을 형식에 맞게 출력한다.

  ```
  ex) 당첨 내역 출력 형식
    
  당첨 통계
  ---
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```
  
- [ ] 수익률을 형식에 맞게 출력한다.

  - `ex) 총 수익률은 62.5%입니다.`

- [ ] 예외 상황 시 에러 문구를 형식에 맞게 출력한다.

  - 에러 문구는 "[ERROR]"로 시작해야 한다.

  - `ex) [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`


## 도메인 규칙/검증
- [x] 시스템은 1개의 로또 발행 시, 6개의 숫자를 뽑는다.

  - [x] 로또 번호는 로또 번호 규칙을 따른다.

- [x] 시스템은 구입 금액에 해당하는 만큼 로또를 발행한다.

- [ ] 시스템은 당첨 기준에 따라 로또 게임 결과를 계산한다.

  - 로또 당첨 기준 및 금액
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

  - [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역을 계산한다.

  - [ ] 당첨 내역을 보고 사용자의 수익률을 계산한다.


## 로또 번호 규칙
- [x] 로또 번호의 숫자 범위는 1~45까지 이다.

- [x] 각 로또 번호는 중복되지 않는다.
